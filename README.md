
# Gestor de tareas

## pequeña aplicacion para gestionar tareas desde la consola

1. añadir una tarea 
2. borrar una tarea 
3. listar tarea
4.  marcar tareas como completadas

## Implemntacion ##

Se utiliza la version de java++ jdk27

Almacenamos las tareas en memoria `Array List`

Gestion del UI con `println` y `Scanner`
